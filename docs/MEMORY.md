- inert placeholder links: keyed off `href` prefix (`http` → new tab + rel, else inert) instead of icon type, so any future placeholder link stays safe by default, not just the ones special-cased.
- decorative icons paired with a visible label: give the `<svg>` `aria-hidden="true" focusable="false"`, so screen readers read only the visible label, never an untitled graphic alongside it.
- experience ordering: `Experience.astro` doesn't sort jobs, renders array as given — caller (index.astro) owns newest-first order. Matches Sidebar/Education's caller-owns-order convention, avoids duplicating sort policy inside the component.
- dark-mode color overrides: plain (unlayered) CSS custom-property rules in `global.css` beat Tailwind v4's `@theme`-layer vars regardless of source order — cascade layers always lose to unlayered CSS. So redefining `--color-navy-900` etc. under `[data-theme="dark"]` repaints every existing `text-navy-900`-style utility automatically, no need to touch component files or add `dark:` variants.
- browser storage calls (`localStorage` etc): wrap in try/catch — Safari private mode and blocked-storage settings throw on access, which would otherwise abort the whole script and break unrelated functionality (e.g. a click handler registered after the throwing line never attaches).
